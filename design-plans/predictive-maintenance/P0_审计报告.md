## 三、静态审计与复用点

| 对象 | 代码依据 | 规划要求 |
|---|---|---|
| 产品 Product | IoTSharp.Data/Product.cs，ApplicationDbContext.Products | 产品定义设备族和点位模板，不代表运行实例 |
| 设备 Device | Device.cs，ApplicationDbContext.Device | 实际 DeviceId、遥测及状态 |
| 资产 Asset | ApplicationDbContext.Assets、AssetRelation | 资产/设备真实绑定待确认 |
| 采集模板 | CollectionPointTemplate（PointKey、SemanticId、BindingId、Address、FieldPath、ValueType） | 模板点不等于已采集的生产数据 |
| 历史遥测 | TelemetryData（DeviceId、KeyName、DateTime、DataSide、Type、Value_*） | 使用历史数据，Latest 不可代替训练历史 |
| 统一读取 | IoTSharp.Data.TimeSeries/IStorage.cs 的 LoadTelemetryAsync | 后续 Worker 只读、异步、限流 |
| Provider | EF/SQLServer、PostgreSQL、InfluxDB 等 | 时间、聚合、缺失样本跨库契约测试 |
| 告警和审计 | AlarmController、RuleAudit | 预测风险要关联已有 Alarm，不代替它 |
| AI/MCP | Services/Mcp、AiMcpCenter.vue | 初期仅只读解释与取证 |
| 数字孪生 | IoTSharp/Services/DigitalTwin 与 ClientApp/src/digital-twin | 后期只读叠加，不能改现场控制 |

### 必须在 P1 前落实的代码风险

1. AlarmController.AckAlarm 与 ClearAlarm 在方法内直接按 Alarm.Id 查找，没有可见的 Tenant/Customer 显式过滤。需要检查全局授权/过滤及实际跨租户负面测试，**目前仅是静态风险，未认定存在已利用漏洞**；PdM 不应直接复用未验证的写入路径。
2. EFStorage 使用 [begin,end) 历史窗口；InfluxDBStorage.LoadTelemetryAsync 构造查询时使用 ToLocalTime()，需核实 UTC 时区/Provider 语义差异。
3. 采集模板、AssetRelation 的存在不证明现场 Device 映射正确；需通过真实试点数据只读核对。
4. 本阶段未创建 EF 迁移，不修改 Main Host、实时规则链或 Reliable Spool。

## 四、试点点位字典与数据质量

试点建议：工业电机单设备族，3～10 台设备，附 P0_试点点位字典_示例.csv。候选测点：
- bearing_temperature，°C，轴承温度
- motor_current，A，电流
- vibration_rms，mm/s，振动均方根
- motor_speed，rpm，转速
- run_state，0/1，运行/停机
- run_hours，h，累计运行小时

**全部为合成样例，并非当前生产数据库实际字段。**

质量门禁检查：点位采样周期、UTC 设备时钟、窗口覆盖率、长时缺失、重复/乱序、单位混用、离线、工况切换、传感器更换、历史可用天数及真实维修故障标签。无运行状态不能判断健康；无故障标签不能声称已校准故障概率/RUL。

P0 合成场景示例阈值：15min 窗口、60 秒间隔、80% 覆盖率、温度持续上升且斜率 >=0.4 °C/min 提示 Attention。**仅是测试数值，不能直接用于现场。**

## 五、独立回放测试结果

目录：tools/pdm-p0。
执行：node --test tools/pdm-p0/replay.test.mjs。
数据：fixtures/pilot-motor.synthetic.json，provenance=synthetic-only。

- **测试 12 项通过，0 项失败。**
- DQ-01：15 分钟正常数据窗口。
- DQ-02：缺失、单位错误、NaN、离线。

局限：目前测试的是**独立合同/合成数据**，还未接入 IoTSharp 的真实时序 Provider、租户安全上下文、Alarm API；Node 内置 sqlite 仍显示 Experimental 警告，P1 应按 .NET10 生产 Provider 实现。

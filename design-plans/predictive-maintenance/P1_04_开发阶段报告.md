# IoTSharp 预测性维护 P1-04 开发阶段报告

日期：2026-11-12；分支 Develop；当前源码 HEAD 56fa1d63。

## 结果

P1-04 的 Worker/只读历史适配器/独立持久化/风险状态机已实现，默认禁用，未部署到生产。

- 独立 PdmDbContext 及实体配置；不参与主 ApplicationDbContext 自动迁移。
- 风险事件按设备、租户和 Profile 确定作用域，重复窗口持久化只执行一次，重启可续接状态；恢复需多个连续正常窗口，Unknown 不解除风险。
- 一台设备出错不阻碍其他设备的 Worker 执行，每台独立 EF DbContext/事务。
- 真实 SQLite 内存 DB 验证风险写入、幂等和表索引。
- 三种 Provider 初始化 SQL 离线生成：Sqlite/SqlServer/PostgreSql，SHA256 校验清单，未连接任何真实库。
- P1 47 项隔离测试通过；本阶段主要编译 Data 与 IoTSharp 0 个错误。
- 没有向 PLC/MES 写指令，没有向业务数据库写入，没有 Git 提交/推送。

## 尚未完成 / 上线门禁

- 初始 SQL 只是 DDL 预览，不是带版本历史的正式 EF Migrations；DBA 尚未验收/部署 SQL Server、PostgreSQL 实库。
- IStorage 的历史查询不支持服务端 Top/Limit 或取消；目前限量只在读取结果返回后检查，须改进后方可生产启用。
- 仅单实例人工确认，没有分布式租约/选主；多实例禁止上线。
- P0 真实设备绑定/点位/故障标签及 1h/4h 长稳未完成。
- 没有前端、预测告警 API、维护工单闭环，也未连接真实 PLC/MES。

结论：P1-04 代码与隔离验收通过，生产部署门禁未通过，必须保持 PredictiveMaintenance:Enabled=false。

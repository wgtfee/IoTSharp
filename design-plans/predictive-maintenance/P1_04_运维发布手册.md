# IoTSharp PdM P1-04：独立 Worker 发布与回滚说明

日期：2026-11-12；工作区：H:\code\Industrial.Platform\IoTSharp-master

## 已实现的能力

- 独立 PdmDbContext；四张实体表：PdmDeviceProfile、PdmPointPolicy、PdmHealthSnapshot、PdmRiskEvent。
- PdmEvaluationWorker：后台低频轮询、每轮限量设备、设备独立 DI scope、故障设备不影响其他设备。
- PdmCycleProcessor：设备配置核验、历史只读、窗口幂等检查、Serializable 事务、健康快照及风险状态一次保存。
- PdmRiskEventTransitions：风险 Opening / Updating / RecoveryPending / Cleared。停机、离线或 Unknown 不自动清除；连续正常窗口才能恢复。EventKey 包含租户/设备/配置版本/异常片段。
- PdmTelemetryHistoryReader：校验 UTC、Key 和运行信号；要求现场映射审核完成后才读历史。
- Startup 仅增加显式 AddPredictiveMaintenanceP1 注册；默认没有 PdM DbContext、没有 PdM Worker，也没有数据库查询。

## 离线数据库脚本

目录：design-plans/predictive-maintenance/migrations

- PdmInitialSchema_sqlite.sql
- PdmInitialSchema_sqlserver.sql
- PdmInitialSchema_postgresql.sql
- PdmInitialSchema_checksums.json

生成命令：

    dotnet restore tools/pdm-schema/PdmSchemaExport.csproj --ignore-failed-sources -p:NuGetAudit=false
    dotnet run --project tools/pdm-schema/PdmSchemaExport.csproj --no-restore -- design-plans/predictive-maintenance/migrations

脚本从真实 PdmDbContext.Database.GenerateCreateScript 离线生成，每份四张表。当前没有执行数据库连接、SQL或物理建表。它们属于首次部署 DDL 预览，不是带历史管理的 EF Migration。SQL Server、PostgreSQL 的实库 DDL、迁移/回滚与运维权限仍须 DBA 审核，不能把生成脚本当已上线。

## 启用条件（默认全部关闭）

环境配置节 PredictiveMaintenance：

Enabled=false、SchemaReady=false、SingleInstanceAcknowledged=false、PointMappingsApproved=false；
MetadataProvider=Sqlite/SqlServer/PostgreSql；
PollSeconds=60、MaxProfilesPerCycle=5、MaxPointsPerDevice=12、MaxHistoryRowsPerDevice=5000、RecoveryConsecutiveWindows=3。

独立连接从 ConnectionStrings:PdmMetadata 取得，不能与 IoTSharp/TelemetryStorage 连接字符串相同；密码应使用现有安全配置方式而非放进仓库。

正式启用前需确认：试点设备/产品/资产/点位、数据单位和运行状态；独立 PdM 表的 DBA 审批和已实际建表；单实例运行确认；生产 Provider UTC 行为；跨租户和 JWT 负面测试；数据质量、吞吐与 1h/4h 长稳。

当前 IStorage.LoadTelemetryAsync 不支持 CancellationToken 和原生 TOP/LIMIT。MaxHistoryRowsPerDevice 是取回数据后的校验，不能限制数据库侧查询量和内存；**不能把它视为已经具备生产限流能力**。在补完安全的有界历史读取接口和长稳验收前，禁止生产启用。

## 回滚

将 PredictiveMaintenance:Enabled 设为 false 并按既有发布流程重启；不删 PdM 风险/快照数据、不改现有 IoTSharp 主库迁移或其他生产流程。没有实现集群分布式 lease；单实例确认不是自动选主锁，多副本环境禁止同时启用。

# 模板驱动免示教取放与码垛实施方案

日期：2026-11-12。状态：实施规划；各项验收未通过前，不标为已实现或可用于现场执行。

本方案整合用户 `zero_teach_scene_building_R4.md` 与本次评审意见，建立在 [05 自动规划 V2](05-机器人取放与桁架码垛自动规划V2.md) 和 [06 R3 评审采纳与修订意见](06-R3评审采纳与修订意见.md) 上。沿用原 V01—V20、AC、RC 追踪关系；R4 的 V33—V46 为待合并来源编号，不覆盖旧要求。本轮先完成可独立验证的声明、位置派生基础，再逐阶段完成轨迹执行和完整工艺。

## 1. 产品目标与范围

默认流程：放置已准备的组件、机器人和工具 → 选择来源与目标或码垛配方 → 自动推导取放位置 → 生成工艺步骤和候选轨迹 → 查看检查结果 → 保存工艺。

场景编辑者不逐个创建工作点、不手填内部 ID、不逐段拼运动节点。模板维护者提供可复用的语义声明；手动点、锁定约束和必经点作为显式调整手段。

“免示教”指声明完整的场景无需逐点示教，不表示无需模板、实际尺寸、工具标定或物料关系。首期优先覆盖现有丝锭、隔板、料位、转台、托盘及两工具桁架，不同时扩大到任意模型抓取识别。

沿用边界：不引入第二套动作流或桁架调度器，不替换现有物料身份与交接规则；仿真、监视、真实设备执行隔离。现场控制、标定、动力学、柔性物体抓取和多机器人协作分别验证。

## 3. 声明与权威来源

### 3.1 分层

| 层 | 内容 |
| --- | --- |
| 模板 | 槽位和接触面的参数化定义、工具 TCP、抓取规格、允许朝向、实际轴能力、碰撞体、验证适用范围 |
| 实例 | 模板版本、尺寸等参数、对象变换、安装偏移、实际载体身份 |
| 任务 | 来源、目标、工具、物料、配方、允许调整范围 |
| 覆盖 | 明确固定的工具目标或关节目标、锁定约束、禁用候选、必经点及来源 |

模板保存位置规则及参数，不能只存一组适用于某个尺寸的固定偏移。修改台面高度、夹具间距、工件规格或实例尺寸后，相关派生及验证应失效。

### 3.2 坐标语义

必须分别定义：物流方向、接触外法向、工具接近轴、接近运动方向和退出方向。所有位姿声明参考对象、可选模型节点、长度单位、旋转约定与版本。

以朝上表面为例：法向为 +Y，预取点位于上方，向接触点运动为 -Y，退出为 +Y。物流端口方向不直接代替上述方向。

接触点可位于允许接触的表面，不能把“必须在碰撞体之外”作为通用体检规则。近似碰撞体和接触豁免必须按对象对及工艺阶段限定。

### 3.3 派生与覆盖

工具目标/关节目标表达“目标是什么”；自动派生/手动覆盖表达“目标来自哪里”。合同设计避免将这两个维度混为一体。派生记录至少包含稳定身份、来源引用、规则版本、输入版本及失效状态。

派生工作点可作为既有工作点合同的只读投影。源声明为编辑权威，投影为派生结果；同一目标不保留两份可独立编辑的坐标。物化结果必须遵守现有工作点的参考坐标语义，避免再次叠加槽位偏移。

转换为手动目标后保留来源及差异。重新生成不静默覆盖用户修改；依赖变化时标记待复核，重新验证，不能因保护用户修改而继续运行失效轨迹。

## 4. 派生与候选选择

1. 读取固定版本的声明、实例变换、实际物料/载体身份、工具、配方和起始状态。
2. 检查声明完整性、数值有效性、物料兼容性、坐标与单位；缺失即给出可定位原因，不从最近对象或模型外观补值。
3. 基于声明的抓取关系生成候选；记录对象相对 TCP 的变换，贯穿抓取、持料搬运与放置。
4. 根据真实机构能力、允许朝向、轴限位和可用检查进行初筛；未检查项保留状态，不当作通过。
5. 在版本化规则内排序，按固定次序尝试完整取放链：接近、抓取、退出、搬运、放置、撤离。
6. 关键位姿可达不代表中间路径可行。某候选完整规划失败时，在预算内尝试下一候选；全部失败时分别报告不可解、冲突、预算耗尽或不确定。
7. 对最终执行曲线检查几何、时间、轴约束、碰撞和交接；阶段未具备的能力明确显示为未完成。
8. 保存决策记录、拒绝原因、所选抓取关系、版本、依赖和最终产物。

初期采用固定声明候选和稳定排序，不以缺少可靠依据的“奇异距离”“抓取稳定性分数”冒充已验证指标。硬约束不能被加权评分抵消。等价候选可自动选择；涉及工艺含义的歧义才要求用户选择并保存偏好。

## 5. 生命周期、依赖与执行

| 状态 | 规则 |
| --- | --- |
| 编辑草稿 | 允许自动派生；新输入使旧请求失效；发布结果前核对编辑版本；保留覆盖与撤销 |
| 已发布版本 | 固定声明、规则、配置和验证依据；模板更新不静默改写旧版本 |
| 本次运动 | 绑定实际物料、托盘、起始状态及本段目标；不在运动中自动追随重新派生目标 |
| 下一批或允许停止边界 | 核对身份和状态后，按已声明策略重新派生、规划并检查 |

执行产物保存本次已解析的数值快照及摘要，以支持重开、对照和回放；这些数值不是第二份可编辑权威。稳定工作点 ID 与本次运行绑定分开。

依赖范围采用 06 §4.2 的修正规则，不能恢复 R3 仅扩大 `δ_res` 的范围：完整链接、工具和持料扫掠范围需计入最小净空、模型与变换误差；来源、目标、父坐标、工具、物料、配方、起始状态和占用保持显式依赖。新对象进入范围也须被发现。

候选尚无路径时，使用声明的工作区域或足够保守的查询范围取得环境；最终路径形成后才收敛复用依赖，不形成“先有路径才能查障碍、先查障碍才能找路径”的循环。

新增逻辑继续沿用原动作图调度与轴所有权。联锁规则与保持机制共享，逻辑步内运动推进前完成判定。`FollowTrajectory` 的完整执行链仍按 M0-S/M2a/M2b 落地，不把派生工作点存在当作轨迹执行已经完成。

## 6. 桁架码垛

用户只选择托盘和配方的前提，是模板已带入来源槽位、实际工具抓位、工件规格和轴布局。规则格位由托盘坐标及配方生成，再结合抓取变换计算 TCP 目标。

两轴成组夹具只接受能由实际轴和抓位实现的排列。逐件转向、任意格位、变距或跨层批次需要对应能力，不能通过放料时重新排列或瞬移补足。

搬运高度公式只产生候选：垛顶及沿途障碍、工件和工具下沿、净空均参与；仍须检查横梁、工具顶部、全段碰撞和轴行程。层高明确区分支撑面、物料基准和 TCP；板厚不得在层距和当前垛顶中重复叠加。

M3 保留 48 件及 0/7/8 张隔板、双工具互锁、满托换托、实际托盘身份、基本恢复验收。现有无隔板底层分支不代表流程已完整适配，M1 只开放已适配的模板。

## 7. 声明体检与用户界面

声明完整度与任务验证分开：D0—D3 只表示资料齐备程度；任务检查使用未检查、过期、通过、失败等独立状态。D3 不自动意味着可运行。

模板体检覆盖参考坐标、单位、方向相反约定、尺寸参数变化、物料兼容和具体抓取关系。合成摆放中的不可达不能单独证明声明错误，应区分错误声明与超出模板适用范围。

普通界面展示来源、目标、自动计算结果、失败原因和覆盖入口。高级详情展示引用、版本、候选和误差。缺失声明应定位到需要补充的模板或实例，不要求用户手填内部 ID。

## 8. 实施顺序及当前第一批范围

| 阶段 | 交付 | 必须保留的边界 |
| --- | --- | --- |
| M0 | 声明合同、来源与覆盖、坐标规则、体检基础和保存往返 | 未实现能力不开放；非法数据不能进入运行 |
| M0-S | 定时轨迹贯通加载、求值和轴写入，统一逻辑时间 | 正式发布拒绝测试产物，暂停/联锁有效 |
| M1 | 基础工艺卡、槽位级派生、稳定引用、预览、取消与撤销 | 仅几何结果，不承诺可执行或碰撞通过 |
| M2a | 完整候选链规划、时间/轴约束、实际仿真交接 | 试运行与发布分离 |
| M2b | 最终碰撞、完整依赖、验证记录与正式发布 | 同一产物往返并执行，不静默回退 |
| M3 | 全层码垛、双工具、隔板、换托与恢复 | 保留 V12—V16 及 RC 对应要求 |
| M4/M5 | 自动绕障及独立现场适配 | 分别验收 |

第一批开发聚焦可复用的位置派生与声明校验基础，并接入现有合同或编辑校验链；验证坐标变换、方向、缺失声明和物料/工具不兼容。UI、完整候选回退、碰撞规划及实际运动不得仅因基础模块完成而标记完成。实施记录随实际结果补充。

后续 X1 先考虑已声明接触条件的刚性箱体和板件；袋类及柔性物体不纳入首批包围盒推断。X2 摆位建议和 X3 任务建议独立增量，不占用基础工艺卡交付。

## 9. 验收要求

沿用 V33—V46 的产品目标，增加以下具体边界；与原 V、AC、RC 建立关联，不删除原要求。

| 用例 | 通过条件 |
| --- | --- |
| 自动派生 | 已声明的来源、目标、工具无需手建点即可产生明确参考坐标下的候选 |
| 坐标旋转 | 来源或托盘旋转后，位置、接近方向和工具朝向保持正确，不把局部偏移当世界偏移 |
| 参数变化 | 模板实例尺寸变化触发对应位置及验证失效 |
| 方向约定 | 外法向、接近与退出关系一致，不能混用物流方向 |
| 缺项与非法数值 | 缺少引用、工具、物料或方向，零向量、NaN、无穷及不支持变换明确拒绝，不补隐藏默认值 |
| 抓取到放置 | 使用同一物料相对 TCP 变换；放置不能改变抓取关系掩盖不可达 |
| 候选回退 | 第一候选中间路径失败时尝试后续候选；全失败保留具体原因 |
| 发布与运行冻结 | 模板更新不改旧发布版本；运动中目标变化不自动追随；在允许边界重新检查 |
| 保存重开与稳定 ID | 派生来源、规则、引用和覆盖不丢失；旧版本场景保持兼容 |
| 交接与库存 | 无料、未夹紧、目标满位或身份变化不伪交接；释放后物料继续参与占用与碰撞 |
| 桁架配方 | 实际轴和抓位匹配；层高、隔板和批量一致；不靠瞬移补足机构能力 |

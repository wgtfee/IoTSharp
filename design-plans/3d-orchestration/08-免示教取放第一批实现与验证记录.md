## 3. 位置与方向如何确定

每个槽位的 `toolTargets` 最多 32 项，可不声明或为空。非空候选必须提供版本、唯一 `templateId`、工具引用、匹配的物料类型、TCP 局部位置和姿态、正的接近与退出距离。槽位需要明确接触外法向，工具需要明确接近方向。长度单位为米，姿态为 XYZ 欧拉角、弧度。

静态槽位的完整坐标系由对象或准确子节点的世界变换与槽位局部位姿组合得到。以 `S` 表示该完整坐标系，`p` 表示候选 `tcpOffset`，`n` 表示变换到世界坐标后的单位外法向：

```text
contact  = S × p
approach = contact + n × approachDistance
retreat  = contact + n × retreatDistance
TCP 世界姿态 = 槽位世界旋转 × 候选 tcpRotation
```

工具接近方向经过目标 TCP 姿态变换后必须与外法向相反。模块只接受米制、Y 向上和刚体坐标变换；缺失锚点、零向量、非法数值、缩放、镜像、剪切或方向冲突会明确拒绝。没有“找不到子节点就退到根节点”的隐藏回退。

动态槽位，包括运行载体、码垛层位、隔板层位及从物料确定接触面的槽位，必须由调用方提供完整 `resolvedSlotFrame`：`slotId`、`ownerId`、`stateRevision`、世界矩阵。已解析的完整槽位坐标系不会再次叠加局部位姿。禁止以 `nearest` 选择载体。

本批检查上述身份与版本字段是否明确，并纳入输入摘要；**尚未实现对库存、状态版本新鲜度或运行载体身份的实时复核**。快照解析和允许重规划边界属于后续运行时接入工作。

候选 ID 由槽位与模板标识生成，位置变化不改变 ID。`inputSignature` 是输入 JSON 摘要，用于比较与诊断，不是密码学签名、缓存授权或发布冻结证明。批量接口按模板标识排序；某个候选几何不兼容时保留原因并继续其他候选。全部候选失败时返回空候选及失败记录；声明本身非法则整体拒绝。此行为不等同于完整路径规划失败后的候选回退。

## 6. 后续开发顺序

1. 接入准确的场景对象/子节点与动态载体快照解析；补齐槽位、模板、工具、状态版本的依赖与失效检查。
2. 在编辑器中接入模板声明和候选预览，让用户通过来源、目标和工具配置取放任务；缺项诊断直接定位到相应配置。
3. 用同一物料相对 TCP 变换贯穿取料和放料；机器人运动学与桁架实际轴模型分别检查可达性、行程和能力限制。
4. 验证整条候选路径的碰撞、净空、时序和交接条件，再生成工作点/轨迹；实现完整候选回退与全失败诊断。
5. 接入发布冻结、运行冻结、版本校验、数据库保存重开及真实浏览器回归，再扩展完整码垛、隔板、换托和恢复。

工作区还存在其他任务改动、历史临时文件和脏子仓库，均未纳入本批提交或清理。预测性维护相关代码也保持原样。上述构建是当前共享工作区的构建证据，不是对这些其他任务的功能验收。

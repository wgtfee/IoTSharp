# 选中什么就配置什么，编辑与调试保持同一上下文

日期：2026-11-05。Written against：`Develop / 4d3b7feb`。状态：待实施。

## Evidence chain

- Surface：`/iot/digital-twin/workbench` 的 3D、流程、分屏、路线属性和运行预览。
- Problem：完整路线属性固定读 routes[0]；两处撤销对应不同历史；运行时对象定位切回专业编辑；模板与节点编辑缺少稳定的设备上下文。
- Owner：`ClientApp/src/views/iot/digital-twin/workbench.vue:690,1075–1096,1346–1378,1469–1473`；`ClientApp/src/digital-twin/components/ThreeJsEditorHost.vue:17,115,164`；`editor-adapter/ThreeEditorCoreHost.ts:792–810`。
- Design evidence：当前用户可选次路线，界面却描述“当前路线”；动作流 V1 方案 §13 提出双向定位和覆盖节点/边/属性的撤销。该方案是草案，以下交互是本次拟定决策。
- Runtime：ThreeJsEditorHost 将 selection-change 交给工作台；工作台只更新 selected，没有让 route computed 跟随。全局键盘调用 undoWorkbench，画布按钮调用 host.undo。
- Scope：工作台及其实际引用的编辑器/流程组件；共享 2D ActionFlowDesigner 需要兼容。
- Uncertainty：没有本轮浏览器渲染；面板宽度、层级和点击成本需以真实页面任务测试确定。

## Design decision

采用统一选择上下文和编辑事务。任务入口决定呈现哪些配置；布局只决定看 3D、流程还是两者。运行模式另有明确含义，不因为查看、定位或布局变化而改变。

首期保留现有工程主题、Element Plus 控件、3D 交互和专业功能。调整入口与状态关系，不引入第二套组件、路线或运行定义。

## Reuse

- `TwinSelectionInfo`、现有 selectObject/focusSelected、route-point 选择事件。
- `ActionFlowDesigner` 的 focusObjectId、focus-object、scene-snapshots 事件接口。
- `workbenchHistory` 的 80 条历史上限与现有撤销入口，升级为所有持久化编辑的唯一事务入口。
- `ComponentPropertyPanel` 已有分组折叠；`ActionNodeInspector` 已按 Actor 筛选 TCP，可作为其它候选筛选的实现示例。
- `ActionFlowDiagnostics`、`diagnosticLocator.ts` 和现有路径字段。
- 拟新增 `ClientApp/src/digital-twin/authoring/SceneAuthoringContext.ts`：当前工作台 selected、Host selectedRouteId、动作图 selectedNodeId 分别维护，缺少统一选择与显式通知。

## Changes

### 1. 统一选择

Owner：`workbench.vue`、`ThreeJsEditorHost.vue`、`ActionFlowDesigner.vue`、`ActionNodeInspector.vue`。

- 维护对象、路线、流程、节点和诊断字段的选择上下文；这些是 UI 状态，不新建一套领域对象 ID。
- 画布点选路线点更新 activeRouteId；路线选择器、完整属性、测试和诊断使用相同 ID。零路线状态按空状态处理，不自动补一个虚构路线。
- 选择流程节点时保留节点选择，关联高亮 Actor、工作点、TCP、来源/目标槽；不能触发反向选择监听后跳到同设备的另一条流程。
- 设备被多个流程使用时展示关联列表或高亮集合，不总是自动跳到数组里的第一条。
- 定位诊断携带 objectId / routeId / flowId / nodeId / propertyPath，打开相应属性组并聚焦字段。单纯飞到模型中心不算完成定位。
- 运行预览中定位对象调用运行视口的选择与聚焦能力，保持当前模拟/监视状态；明确点击“编辑”才进入编辑状态。

### 2. 单一编辑历史

Owner：工作台 history/keydown、Host undo/redo、流程的 commitFlows/updateNode/updateEdge。

- 全部业务编辑使用统一事务：拖动一次、改一个字段、生成模板一次、换绑一批、删除及引用修复一次。
- 画布内部变换历史不再作为独立用户撤销入口；把提交结果接入工作台事务，内部恢复不能再次生成一条普通编辑。
- 操作节点、属性或绑定时，即使视口处于运行预览也应记录编辑历史；运行数据、计时和遥测不进入历史。
- 编辑运行中的定义先按现有规则暂停预览并标记“配置已修改，需重新运行”。撤销定义变化不伪装成倒放运行时物料或真实设备。
- 两个可见撤销位置如仍保留，必须调用同一命令、同一可用状态、同一操作说明；键盘也一致。
- 历史存纯定义或受控变更，避免反复 normalize 自动迁移影响快照；不复制模型二进制和遥测快照。

### 3. 任务入口与属性范围

Owner：`workbench.vue` 的工具栏、左侧 tabs、右侧对象绑定区。

拟定主任务入口为“搭建 / 工艺 / 信号 / 检查”。保留 3D / 流程 / 分屏作为可收起的布局选择，不继续增加一排同时争夺空间的常驻按钮。

| 任务 | 默认内容 | 高级内容 |
| --- | --- | --- |
| 搭建 | 模型资源、设备树、位置尺寸、端口与路线 | 几何覆盖、手工路线点/边、工程坐标 |
| 工艺 | 当前工位的工艺摘要、参数、模板配置 | 完整动作图、工作点/槽位/TCP/联锁详情 |
| 信号 | 当前工位的信号表和最新值 | 转换、过期判定、绑定引用和技术标识 |
| 检查 | 保存/模拟/发布诊断及定位 | 编译细节、定义 ID、运行事件 |

- 无选择时显示本任务的空状态和可执行入口；不同时展开所有对象的工程表单。
- 简易模式不限制专业图编辑。自定义图的修改规则由参数模板计划定义。
- 普通属性优先用“执行设备、工作点、物料位、工具坐标、执行轴”。稳定 ID 在详情中可复制，业务人员无需输入。
- 原“选择 Asset 后保存即可入库”的提示必须和保存入口保持一致；未入库状态进入命名/选 Asset 的保存流程。

### 4. 候选项过滤与明确错误

Owner：`ActionNodeInspector.vue`、模板参数解析、现有 Validator。

- 轴和姿态限制为当前 Actor 的能力；改变 Actor 后重新校验已有选择，不静默把轴换成第一项。
- 工具坐标归属当前 Actor；物料来源/目标可以属于其它设备，按取放角色、物料类型和当前工艺关系筛选。
- 工作点按动作角色和被操作设备关系筛选；来源设备的工作点不应仅因不是 Actor 自身就被删掉。
- 路线区段改为所选路线下的名称选择，保留高级标识显示；不能要求普通用户手填 Section / Edge 字符串。
- 候选不兼容时显示原因；保存、模拟和发布的诊断仍由同一规则判断。

### 5. 调试范围与文案

Owner：`SceneFlowRuntimePanel.vue`、`ActionFlowDesigner.vue`、`workbench.vue:2454–2462`。

- 当前三维执行控制是整线范围。按钮明确写“按最新配置重启整线”，保留整线暂停/继续/复位说明；选了某图不代表只运行该图。
- 现有单路线测试保持独立范围。尚未实现的真实三维单节点断点、单步与单设备隔离运行，不通过新增按钮宣称支持。
- 独立图调试与三维联动分开标注；真实命令执行继续要求已发布版本及服务端执行权限，布局选择不得触发。
- 等待状态展示所等设备、信号、物料、工位完成组或联锁，并支持定位。可先使用运行器已有字段，缺失字段再补结构化诊断合同。

## Scope

- Inherit：同一工作台的搭建、动作图、路线、绑定和诊断。
- Verify：3D / 流程 / 分屏切换，2D 调用 ActionFlowDesigner，专业快捷键、多选拖动、编辑子节点与组件属性。
- Exclude：改变仿真调度、替换 Three.js、增加物料引擎、重构全站布局。

## Validation

- 两条路线有不同速度，选择第二条修改速度后第一条不变；测试运行明确对应目标路线。
- 移动设备→改轴参数→新增动作节点→改边→换绑定，连续撤销按用户操作逆序恢复；重做和保存重开一致。
- 同一设备同时参与两条流程，节点定位不会跳错图或清掉节点选择。
- 运行预览中的对象/错误定位不自动进入编辑，不重建整线；明确重启操作才重建。
- 1366×768、1920×1080 及长名称验证：选中名称、主操作与当前属性可见，侧栏可收缩；具体尺寸依据渲染结果调整，不预设未经验证的密度结论。

实施后从 `ClientApp` 执行 `npm run typecheck`、`npm run build`、`npm run verify:v7-components`、`npm run verify:scene-action-flows`。增加选择/历史事务行为测试；浏览器回归必须实际操作上述混合编辑序列。

## Stop conditions

- 若某类内部编辑无法产生稳定事务，先完成该入口适配，不同时保留两套相互看不到的用户历史。
- 若运行器无某种定位或等待信息，标明缺失并补接口，不能用猜测状态填充诊断。

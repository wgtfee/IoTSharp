# IoTSharp 2D 设计器查漏补缺与验收记录

日期：2026-09-28

## 1. 本轮范围与结论

依据《IoTSharp_2D数字孪生场景设计器详细设计_V1.md》继续修补现有专业设计器；保留亚特模板、现有 2D/3D 业务合同和独立页面，不重建一套设备、路线或数据库体系。

本轮完成代码修补及前端自动化验证。真实浏览器操作、SQL Server 保存发布、现场 PLC 数据联调仍待验收，不能以 API 替身或内存数据库测试代替。

## 2. 已实现的修补

| 范围 | 修补结果 |
| --- | --- |
| 拖动与多选 | 点击已选对象保留整组选择，整组移动过滤对象锁和图层锁；Vue 响应式对象安全克隆，避免 structuredClone Proxy 异常。 |
| 复制 | 副本分配独立业务对象身份，不自动复制设备遥测绑定；2D 像素偏移不再写入 3D Transform。 |
| 端口和路线 | 内置设备具有默认端口，旋转时端口同步旋转；禁止对象自身连线；删除点/边同步清理岔口规则、选择和起点引用。 |
| 动作编排 | 2D 页接入共用 Action Flow V2 编辑器，可添加互锁、物料槽并写回同一份场景清单。独立流程支持仿真；实体机械动作、真实设备执行仍由 3D 入口承担。 |
| 键盘隔离 | 按可访问性检查要求，快捷键仅作用于设计器内部；输入框、动作编排和其他弹窗不触发画布删除/撤销。 |
| 保存并发 | 保存时记录场景、版本和提交快照。请求返回时保留保存期间的新编辑，同时采用服务器最新 revision，提示再次保存。 |
| 场景切换 | 忽略迟到的旧场景加载结果；保存、发布等操作中禁用切换；新建、恢复版本对未保存修改明确确认。 |
| 导入与发布 | 导入先构造临时清单并校验，文件损坏不替换草稿；读取文件期间发生编辑则拒绝覆盖。发布前进行前后端校验，确认后再次检查版本和快照。 |
| 运行预览 | 读取不可变发布版本，退出时恢复未保存草稿；运行加载与场景加载使用独立状态，取消请求不清掉下一次加载状态。 |
| 遥测绑定 | 按业务 bindingKey 对齐版本行 GUID；与 3D 共用白名单转换器，支持字符串布尔、枚举/区间颜色、格式文本和进度变换。 |
| 路线运行显示 | 路径按图拓扑和共享 RouteEngine 解析，不按 edges 数组顺序拼接；PLC 岔口值进入解析上下文，过期决策不猜测分支。就绪、放行、占用等信号缺失时显示阻断。 |
| 托盘槽位数组 | 预览和 Viewer 使用同一个 PLC 数组投影函数；过期数组不当作当前托盘位置，托盘图层位于设备图形上方。 |
| 断网恢复 | 批量轮询单请求在途，失败标记过期并持续重试，旧请求不能回写其他场景。 |
| Viewer | 同页切换 sceneId/version 会重新读取指定发布版本，旧响应不能覆盖新版本；无效版本参数明确报错。 |
| 共享绑定回归 | 修复 3D 文本等更新恢复掉动态设备颜色的问题；过期动画停止，恢复时保留最后有效的材质状态。 |

## 3. 自动化验证

### 已通过

- `npm run typecheck`：完整前端类型检查通过。
- `npm run build`：正式构建通过；原有第三方注释、分包等警告保留，不将警告算成编译错误。
- `npm run verify:2d-designer`：基础回归及 11 项真实 Vue setup 状态回归全部通过。
- `npm run verify:flow-safety`：互锁停止/恢复、坏质量拒绝、只读绑定、危险超时及 14 类无效流程拒绝均通过。
- `npm run verify:motion-limits`：22 项越界命令拒绝、精确边界、不可达目标立即报错和禁止静默截断均通过。
- 基础回归覆盖响应式克隆、复制身份、2D/3D 坐标隔离、拓扑插值、PLC 分支、数组槽位、绑定转换与 Three.js 实际对象结果一致性、过期动画停止、旋转端口和引用清理。
- 组件回归覆盖保存中编辑、旧场景响应、只读预览及草稿恢复、取消预览与切换冲突、坏文件导入、慢文件导入、弹窗快捷键、多选拖动及锁定、发布前并发修改、断网重试、Viewer 原地切换版本。

组件回归执行真实组件代码和 Vue 响应式；仅网络 API、浏览器生命周期、SVG 坐标矩阵为测试替身，不是像素级或浏览器端到端验证。

## 5. 明确边界

- 2D 生产运行态为遥测投影；不新增一套本地物理仿真冒充真实生产状态。
- 2D 可编辑共用动作流及独立流程仿真；完整机器人/桁架机械联动继续由 3D 运行预览执行。本轮没有宣称 2D 已具备完整 3D 物理执行器。
- 未扩展模板中心、多人协同、SVG 可视化建模器、大型场景虚拟化等后续版本事项。
- 修改留在本地工作区，尚未提交或推送远程。保留了工作区原有无关修改和临时文件。
